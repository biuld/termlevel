# Termlevel icon v1

Generated with the built-in image_gen tool. Used as the app packaging icon through the `icon` field in `nsh.json`. NSH converts the source PNG into the target platform's icon resources.

The layered terminal tiles represent persistent sessions and split-pane workspaces. The terminal prompt carries the core identity, with charcoal, purple and blue reflecting the native workspace UI.

## Generation prompt

Use case: logo-brand.
Asset type: a finished, standalone macOS application icon for Termlevel, a native desktop terminal app.
Project context: a fast Rust-owned terminal engine inside a native macOS UI; persistent terminal sessions, flat tab groups, and flexible split-pane tiling. The name suggests terminal workspaces organized in layers and levels. The app's UI is restrained charcoal with purple and blue group accents.
Primary request: design ONE distinctive, premium app icon, square 1024x1024 composition. A rounded-square graphite terminal tile with two subtly offset terminal panel layers visible behind its upper/right edges, suggesting multiple panes and levels. The front panel carries one bold, beautifully proportioned terminal prompt chevron and a small underscore, integrated into the geometry rather than generic printed type. Let the stepped layering subtly echo an L. Use lavender/blue-violet as the main accent with a restrained icy cyan highlight and warm off-white prompt detail. Keep the central mark very legible at 32 pixels.
Style: contemporary native macOS icon, precise geometric silhouette, satin ceramic and anodized dark metal feel, very shallow sculpted depth, soft bevels, controlled soft lighting, crisp contours, very restrained gradients. Sophisticated, confident, quiet. Mostly frontal with only a hint of depth.
Composition: one icon centered, generous balanced safe margins, square canvas, the graphite rounded-square tile is part of the icon; outside its silhouette is genuinely transparent. No staging, no desk, no surrounding scene, no comparison sheet.
Constraints: no app name, no letters or words, no tiny interface chrome, no traffic-light buttons, no screenshots, no busy code, no mascots, no sparkles, no brain or AI motifs, no watermark. Make it an original app identity rather than imitating an existing terminal app logo. The prompt glyph and layered levels should read as one coherent emblem.
