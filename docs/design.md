# UI 与主题

## 设计方向

多终端同时展示的交互、实现说明与验收边界见 [多终端平铺设计](terminal-tiling.md)。

采用「统一窗口栏 + 独立 pane」布局。窗口底板承载顶部窗口栏，下方侧栏和终端分别作为带圆角的停靠面板；悬浮感由留白和表面明度差表达。

- 侧栏默认 208 pt，可调范围 176–288 pt，收起为 44 pt。
- 顶部统一 40 pt 窗口栏，系统窗口按钮与侧栏开关固定在左侧，应用名居中。侧栏展开、收起和悬停不移动窗口控件。窗口栏空白区域可拖动窗口。
- pane 顶部直接接在窗口栏下沿，不额外留白；内容区左右、底部外边距和 pane 间距均为 8 pt，侧栏与终端顶部、底部对齐，圆角 12 pt。侧栏顶部为 36 pt Sessions 标题，收起时显示终端图标；终端工具栏同为 36 pt。两栏之间的空隙承载缩放命中区，拖动期间实时跟随侧栏宽度。
- 固定标签与普通标签均为 28 pt 单行布局，只显示图标和名称。移除固定卡片、目录副标题和大图标底座。
- 分组使用纯色标记、组名与细引导线。标记左下角为 3 pt 小圆角，其余为半圆；不含文件夹图案。展开时标记 14 pt，标题 12 pt、中等字重、使用中性正文色，单行省略，整行高 28 pt。展开的分组直接平铺在侧栏上，不设置分组卡片底色和外层圆角；组头悬停只显露操作按钮，不再叠加整行底色。选中的终端保留一层中性选中底色。实色 `group-*` 用在组标，以及组内选中标签的终端图标；组名保持中性色。成员左侧仍是低对比 `group-*-line`，引导线内侧与 tab 左缘之间留 `gap-group-guide`（6 pt）；不再在 tab 内叠加彩色短竖条。数量移入组头 tooltip，更多按钮仅在悬停、键盘焦点或编辑期间显示。
- 垂直拖动标签可排序，并拖进另一个分组。拖到已有分组的标签上会加入该组；拖到没有分组的标签上会和它组成新组，路径和组名取被拖到的标签，不打开分组编辑。组头高亮表示放入该组，标签高亮表示与该标签成组，标签之间的线表示插入位置；松手在侧栏外或横向滑开则取消。折叠的组头也是目标，放入后展开。拖动不改变 session ID，固定标签只在固定区里重排。
- 收起侧栏时不铺分组底色。组标仍是展开态的 14 pt 标记，在行内居中，左侧低对比 1 pt 颜色线串起整组。折叠组保留当前选中的标签，其余标签用 `+N` 圆形计数入口表示；点击计数展开组。切换到组外时计数包含全部隐藏标签。
- 鼠标移入收起的侧栏时，以浮层展开至保存的侧栏宽度，覆盖终端而不挤压内容；移出后收回。分组编辑浮层打开期间保持展开，手动展开侧栏仍使用固定分栏布局。
- 收起状态（含悬停浮层展开）禁用分界拖动，使用普通光标，不显示拖动悬停高亮；只有手动固定展开时允许调整宽度。
- 搜索、新建分组、设置收至侧栏底部，旁边显示会话数量，不额外画横向分隔线；新建终端保留列表入口和工具栏按钮。侧栏、工具栏和快捷键新建的终端不进入当前分组；只有组内新建和新建分组会放进组。
- 终端 pane 包含会话工具栏和正文，底色一致，整体圆角裁切。正文左右及底部内边距 16 pt，顶部不留内边距，滚动内容直接接工具栏下沿；滚动网格和原生 Input 保持同一个内容坐标原点。没有常驻状态栏，进程退出或错误才显示状态。
- pane 内的工具栏左侧显示终端图标和初始目录，窄窗口改为会话名；右侧提供新建与更多操作。工具栏内容与正文的左内边距一致。窗口拖动由顶部统一窗口栏负责。预览身份仍由终端欢迎信息与设置说明明确展示。
- 界面默认用平台字体 `system-ui`。`SF Pro Text` 不是已安装的字体族，不能当作 `font-sans`。设置里可以选择已安装的界面字体，以及终端和工具栏路径共用的等宽字体。工具栏路径用 body 字号和终端的等宽字体，没有单独字号；快捷键用所选等宽字体，字号与 caption 相同。字级见下方「字体」。图标按钮 26 pt、操作按钮 28 pt、输入框 30 pt。
- 居中对话框使用 NSH `Dialog`。运行时只提供层和关闭行为，外观由应用绘制：实色 `bg-popover`、`radius-dialog`、细边框、轻阴影，底下是均匀 `bg-scrim`，不用玻璃。标题和说明在上，分区在中，操作在底部分隔线下右对齐。确认删除使用 `alertdialog`。Escape 和点击遮罩关闭。分组编辑仍是锚定组头的 `Overlay`，不是这个对话框。
- 设置面板是两栏：左侧为 Appearance、Terminal、Interface、Shortcuts、About，右侧只显示当前分区。外观为 System / Light / Dark，默认跟随系统；切换外观保留终端实例。终端可选等宽字体，字号 10–24 pt，默认 Menlo 13 pt，行高为字号加 `line-gap-terminal`。工具栏路径使用同一等宽字体，字号保持 body。界面可选 System、Helvetica Neue、Avenir Next、Gill Sans、Futura、Georgia，字级仍来自主题。会话和设置仍不持久化。

## 字体

界面文字用 `ui/type.tsx` 的角色，不在组件里另写字号。字号和行高只写在 `theme.json`。字体族由设置选择，默认界面是 `system-ui`，默认等宽是 Menlo。

| 角色 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `heading` | 18 | 22 | medium | 空状态 |
| `title` | 15 | 20 | semibold | 对话框标题 |
| `body` | 12 | 16 | regular | 标签名、设置行、按钮、组名（组名用 medium） |
| `label` | 11 | 15 | medium | 设置分区、分段控件 |
| `caption` | 10 | 13 | regular | 说明、计数 |
| `mono` | 10 | 13 | 所选等宽字体 | 快捷键和设置里的字号读数 |
| 终端 | 13 | 字号 + 8 | 所选等宽字体 | 终端默认字号和字体，由设置调整 |

不使用低于 10 pt 的字号。原先与 caption 相同的 `text-micro` 已去掉。

## Fleet Dark / Light 配色

配色采用 Fleet Islands UI 的 Dark / Light 方向，数值映射依据 [Fleetty 的深浅色主题源码](https://github.com/erenozen/Fleetty/tree/d206733e56c1b16d1fa5f09e322ae8ec8d13a25e/themes)（MIT）。这是公开移植版本，仓库说明来源为 Fleet 导出的主题；没有把它当作官方完整主题分发。设计背景参考 [JetBrains 的 Islands UI 说明](https://blog.jetbrains.com/fleet/2024/12/introducing-fleets-new-islands-ui/)。

| 用途 | Dark | Light |
|---|---|---|
| 窗口底板 | `#090909` | `#eeeff0` |
| 侧栏 / terminal pane | `#18191b` | `#ffffff` |
| 主文字 / 终端默认文字 | `#e0e1e4` | `#090909` |
| 次级文字 | `#909192` | `#747474` |
| 弹层 | `#252629` | `#ffffff` |
| 主操作 | `#0870e4` | `#0870e4` |
| 焦点 | `#2a7deb` | `#2a7deb` |
| 危险操作 | `#ec5d6f` | `#c72c49` |

选中、悬停、边框和次级文字取源码对应语义颜色。源码的透明叠色预先合成在 pane 底色上，应用仍使用不透明表面。九种分组标记使用同套蓝、紫、青、橙、黄、粉、绿、灰、红，收起态隐藏数量入口的底色和引导线从它们合成。预览提示使用 Fleet 的青色关键字和蓝色链接色。

本次映射覆盖工作区、控件、分组以及终端默认前景、背景、光标。ANSI 16 色仍是 NSH 固定调色板，256 色与 truecolor 保持程序语义；不把编辑器语法高亮当作终端输出重着色规则。

## 表面与层级

应用自定义界面统一使用实色表面，不设置 Liquid Glass、背景模糊或平台半透明材质。

- 窗口底板使用 `chrome`，暗色下比 pane 更深，浅色下使用浅灰。固定展开、收起和悬停展开的侧栏都使用不透明 `sidebar`，与终端表面接近。悬停展开时不改变底色，通过细边框与轻阴影表达覆盖关系。分组在侧栏上平铺，颜色仅用于组标、成员引导线及活动终端的图标；不叠加分组面板底色。
- 固定面板通过 8 pt 留白分隔，不加阴影。缩放指示线仅在固定展开态的悬停或拖动期间显示；收起和临时悬停展开均禁用缩放。
- 会话工具栏底色与终端一致。目录和按钮直接放置在工具栏上，不设置胶囊底座；按钮保留悬停、按下与键盘焦点反馈。
- 分组编辑浮层和 tooltip 使用不透明 `popover`，搭配 `border` 细边框、`radius-overlay` 圆角和轻阴影。
- 选中标签保持实色胶囊，终端保持 `terminal-background`。对话框下方的均匀遮罩仅用于表达模态，不做背景模糊。

## 分组编辑

参考 Firefox 的分组编辑浮层：右键组头或点击更多按钮，在组头旁打开 `GroupEditor`，不再通过原生子菜单选颜色或另开重命名对话框。

- 顶部为九个颜色圆点：蓝、紫、青、橙、黄、粉、绿、灰、红；当前颜色带选中环，配色仍来自主题。
- 每个分组记一条路径。组名默认是该路径的最后一段，仍可在编辑浮层里改名；浮层同时显示完整路径。未命名组显示 `未命名分组`。
- 新建组使用当前终端的路径，颜色从九个分组色里随机取一个尚未使用的颜色；九色都用过后再从全部颜色里随机。仍打开同一个编辑浮层。组内新建的终端从分组路径启动。侧栏、工具栏和快捷键新建的终端仍在组外，并从当前终端的路径启动。
- 拖到没有分组的标签上成组时，路径和组名取被拖到的那个标签的路径，颜色同样随机。
- 提供组内新建终端、取消分组和删除组；取消分组保留终端，删除组需要确认并关闭组内终端。
- 输入框 Enter 或 Escape 关闭浮层，点击外部也关闭。选色后保持输入焦点；关闭不会回滚已经修改的名称或颜色。
- 浮层锚定整个组头，随其滚动、收放而定位，由 NSH `Overlay` 处理屏幕边缘约束；宽 280 pt，维持紧凑密度。
- 浏览器的链接、AI 推荐、保存组、多窗口等操作没有作为占位入口加入当前原型。

## 配置入口

`nsh.json` 的 `theme` 指向 `theme.json`，`appearance` 为 `system`。

`theme.json` 是应用设计值的唯一入口：

| 分类 | Tokens |
|---|---|
| 基础 | `background`、`foreground`、`primary`、`border`、`muted-foreground` |
| 窗口与导航 | `chrome`、`sidebar-*`、`height-titlebar`、`width-sidebar`、`gap-pane` |
| 标签与控件 | `tab-selected-*`、`tab-hover`、`control-hover`、`control-pressed`、`control-selected-*` |
| 分组 | `group-purple` 等，以及各自的 `-muted`、`-line`、`gap-group-guide` |
| 终端 | `terminal-background`、`terminal-foreground`、`terminal-cursor`、`font-mono` |
| 字体与密度 | `font-sans`、`text-*`、`leading-*`、`height-*`、`padding-terminal` |
| 圆角 | `radius-control`、`radius-tab`、`radius-panel`、`radius-dialog`、`radius-overlay` |

`cssVars.theme` 放共用字体与尺寸，`cssVars.light` / `dark` 放完整配色。两个外观的自定义 token 名必须一致。

## 使用规则

TSX 静态样式用语义类：

```tsx
<View class="bg-sidebar rounded-(--radius-tab)">
  <Text class="text-sidebar-foreground text-(length:--text-body)">Terminal</Text>
</View>
```

Canvas 和动态样式读取 `token()`，不复制具体色值。分组数据保存 `purple` / `blue` 等稳定标识，`ui/theme.ts` 将标识映射到主题 token。更换主题后，既有分组也随之更新。

所有居中弹窗在 `Dialog` 的 `class` 中设置 `m-auto`。该属性作用于弹窗本体；NSH 不会自动将固定宽度的弹窗居中。

主题不负责会话和工作区状态；切换外观通过 NSH `setColorScheme()`，不卸载或重新创建终端。UI 主题控制终端默认文字、背景、光标和字体，程序通过 ANSI 指定的颜色保持程序语义。预览的品牌与提示符从主题生成 ANSI 色值；已经写入的 truecolor 字符不会因换主题被重写。

调整主题后运行 `./scripts/nsh build` 生成 token 类型声明，再运行 `./scripts/nsh check`。不要手改 `.nsh/types`。原生平台视觉、输入法与选区仍需单独验收。
